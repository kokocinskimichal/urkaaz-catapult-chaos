# Chapter 1 LDS map previews

Ten PNG previews generated from the current Level Definition System (LDS) definitions.
Each image uses the canonical `7200 × 4800` world and shows terrain, protected
foundations, fortresses, catapults, and map objects with neutral preview graphics.

Files: `chapter1-level-01.png` through `chapter1-level-10.png`.
The `chapter1-contact-sheet.png` file provides a side-by-side overview.
